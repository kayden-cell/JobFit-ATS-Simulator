# JobFit ATS Simulator

JobFit ATS Simulator compares a candidate’s CV with a specific job description. It extracts relevant information, evaluates evidence against the role’s requirements and competency groups, and produces a compatibility summary for human review.

## How it works

1. Add a job description by pasting its text or importing a public job posting URL.
2. Review the qualification requirements and competency groups; edit them to fit the role.
3. Upload a PDF or DOCX CV. The app extracts its text and relevant details for review.
4. Run the comparison. The app checks CV evidence against the role requirements and weighted competency keywords, then creates a report.

The results are an aid to review, not an automatic hiring decision. Imported job details and extracted CV information should be checked against their original sources.
